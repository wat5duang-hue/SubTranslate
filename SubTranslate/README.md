# แปลซับสด (SubTranslate) v2.0

แอป Android แปลซับไตเติลบนหน้าจอ (อังกฤษ ญี่ปุ่น จีน เกาหลี) เป็นภาษาไทย ใช้ได้กับ YouTube, ไลฟ์, อนิเมะ และวิดีโอทั่วไป

- **แตะปุ่มลอย** = แปลซับบนจอตอนนี้
- **กดค้างปุ่มลอย** = เปิดเมนู มี แปลอัตโนมัติ / เลือกบริเวณซับ / ประวัติคำแปล / ตั้งค่า / ปิด
- **ลากปุ่ม** ไปไหนก็ได้ ปล่อยแล้วปุ่มจะชิดขอบจอ และจางลงเองเมื่อไม่ได้ใช้
- คำแปลเป็นตัวอักษรขาวหรือเหลือง มีขอบดำ ปรับขนาดได้ และเลือกได้ว่าจะวางด้านบนจอหรือเหนือซับเดิม
- แปลออฟไลน์ฟรี หรือเปิดใช้ AI (Gemini) ได้ถ้าต้องการคำแปลที่เป็นธรรมชาติกว่า
- มีปุ่มลัดในแผงตั้งค่าด่วน และหยุดอ่านซับเองเมื่อภาพนิ่ง ช่วยประหยัดแบต
- รองรับ Android 8.0 ขึ้นไป แต่ใช้กับ iPhone ไม่ได้

### เพิ่มปุ่มลัดในแผงตั้งค่าด่วน
ดึงแถบแจ้งเตือนลงมาจนสุด กดไอคอนดินสอ (แก้ไข) แล้วลากปุ่ม **"แปลซับ"** ขึ้นมาวางไว้ จากนั้นแตะปุ่มนี้เพื่อเริ่มหรือหยุดได้ทันที แต่ Android จะถามสิทธิ์บันทึกหน้าจอทุกครั้งที่เริ่ม

### แปลด้วย AI
1. ขอ API key ฟรีที่ https://aistudio.google.com/apikey
2. ในแอป ไปที่ส่วน "แปลด้วย AI" เปิดสวิตช์ วาง key แล้วกด **บันทึกการตั้งค่า AI**
3. ถ้า AI ใช้ไม่ได้ (เช่น key ผิดหรือเกินโควตา) แอปจะกลับไปใช้ตัวแปลออฟไลน์ให้เอง
4. ตั้งค่าเพิ่มได้เพื่อให้แปลดีขึ้น ได้แก่ รุ่น AI (เร็ว/แม่นกว่า), ประเภทวิดีโอ, น้ำเสียง (เป็นกันเอง/สุภาพ), ชื่อเรื่องที่ดู และชื่อเฉพาะ/คำศัพท์ (บรรทัดละคำ เช่น `Wolf=หมาป่า`)

> ⚠️ Netflix, Disney+ และแอปที่ป้องกันการบันทึกหน้าจอจะให้ภาพเป็นจอดำ จึงแปลซับในแอปเหล่านี้ไม่ได้

## สร้างไฟล์ติดตั้ง (APK) ทำได้ 2 วิธี เลือกวิธีเดียว

### วิธี A: ให้ GitHub สร้างให้ (แนะนำ ไม่ต้องลงโปรแกรม)

ใช้เบราว์เซอร์บน **คอมพิวเตอร์** เพราะการอัปโหลดทั้งโฟลเดอร์จากมือถือทำไม่ได้

1. สมัครบัญชีฟรีที่ https://github.com
2. กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository** ตั้งชื่อ เช่น `SubTranslate` จากนั้นกด **Create repository**
3. ในหน้าที่ขึ้นมา คลิกลิงก์ **uploading an existing file**
4. แตกไฟล์ zip ที่ได้รับ แล้ว **ลากไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างในโฟลเดอร์ `SubTranslate`** ไปวางในหน้าเว็บ
   - ต้องมีโฟลเดอร์ `.github` อยู่ด้วย ซึ่งเป็นโฟลเดอร์ซ่อน
     - บน Windows: เปิด File Explorer ไปที่เมนู View แล้วติ๊ก Hidden items
     - บน Mac: กด `Cmd + Shift + .`
5. กด **Commit changes**
6. ไปที่แท็บ **Actions** แล้วรอจนงาน "Build APK" ขึ้นเครื่องหมายถูกสีเขียว ใช้เวลาประมาณ 5 นาที
7. คลิกงานนั้น เลื่อนลงไปที่ **Artifacts** แล้วดาวน์โหลด `SubTranslate-apk` คุณจะได้ไฟล์ zip ที่มี `app-debug.apk` อยู่ข้างใน
8. ส่งไฟล์ `app-debug.apk` เข้ามือถือ (เช่น ทาง LINE Keep หรือ Google Drive) แล้วแตะเพื่อติดตั้ง

### วิธี B: ใช้ Android Studio บนคอมพิวเตอร์

1. ดาวน์โหลดและติดตั้ง Android Studio จาก https://developer.android.com/studio
2. เปิดโปรแกรม เลือก **Open** แล้วเลือกโฟลเดอร์ `SubTranslate`
3. รอให้โปรแกรมดาวน์โหลดสิ่งที่ต้องใช้ ครั้งแรกอาจใช้เวลา 10–20 นาที
4. ไปที่เมนู **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
5. เมื่อเสร็จแล้ว กด **locate** จะเจอไฟล์ `app-debug.apk` จากนั้นส่งเข้ามือถือแล้วติดตั้ง

## ติดตั้งบนมือถือ

- ถ้าขึ้นข้อความ "ไม่อนุญาตให้ติดตั้งจากแหล่งนี้" ให้กด **การตั้งค่า** แล้วเปิด **อนุญาตจากแหล่งนี้**
- ถ้า Play Protect เตือน ให้กด **รายละเอียดเพิ่มเติม** แล้วเลือก **ติดตั้งต่อไป** (ขึ้นเตือนเพราะแอปไม่ได้มาจาก Play Store)

## ใช้งานครั้งแรก

1. เปิดแอป **แปลซับสด**
2. **ขั้นที่ 1:** กด "อนุญาตแสดงทับแอปอื่น" แล้วเปิดสวิตช์ จากนั้นกดย้อนกลับ
3. **ขั้นที่ 2:** กด "ดาวน์โหลดคำแปลอังกฤษ → ไทย" แล้วรอจนขึ้นว่าเสร็จ
4. **ขั้นที่ 3:** เลื่อนแถบเพื่อตั้งว่าซับอยู่ล่างจอกี่ % ค่าเริ่มต้นคือ 35%
5. กด **▶ เริ่มแปลซับ** แล้วกด **เริ่มเลย** ในหน้าขออนุญาตบันทึกหน้าจอ
   - ถ้ามีตัวเลือก ให้เลือก "ทั้งหน้าจอ"
6. เปิด YouTube หรือแอปวิดีโอ แล้วแตะปุ่มลอยเพื่อแปล

ถ้าต้องการปิด ให้ดึงแถบแจ้งเตือนลงมาแล้วกด **หยุด** หรือกด "หยุดแปลซับ" ในแอป

## เคล็ดลับ

- ถ้าแปลไม่ตรงซับ ให้ปรับขั้นที่ 3 ใหม่ หากตั้งน้อยเกินไปจะไม่เห็นซับ หากตั้งมากเกินไปจะติดข้อความอื่นบนจอมาด้วย
- ตอนดูวิดีโอแนวนอน แอปจะปรับตามการหมุนจอให้เอง
- ลากกล่องคำแปลไปวางตรงที่ไม่บังภาพได้ และแตะที่กล่องเพื่อซ่อน

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `MainActivity.kt` | หน้าตั้งค่าทั้งหมด และปุ่มเริ่ม/หยุด |
| `OverlayService.kt` | งานหลัก: ปุ่มลอย เมนู จับภาพหน้าจอ อ่านซับด้วย OCR แปลภาษา และกรอบเลือกบริเวณซับ |
| `Translators.kt` | ตัวแปลออฟไลน์ (ML Kit) ตัวแปล AI (Gemini) แคชคำแปล และตัวเทียบความคล้ายของข้อความ |
| `Prefs.kt` | ค่าตั้งต่างๆ ของแอป |
| `OutlineTextView.kt` | วาดตัวอักษรแบบมีขอบดำ |
| `RegionPickerView.kt` | กรอบสำหรับลากเลือกบริเวณซับ |
| `HistoryStore.kt`, `HistoryActivity.kt` | เก็บและแสดงประวัติคำแปล |
| `SubTileService.kt` | ปุ่มลัดในแผงตั้งค่าด่วน |
| `.github/workflows/build.yml` | ให้ GitHub สร้างไฟล์ APK ให้โดยอัตโนมัติ |
